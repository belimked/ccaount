Claude 账号使用说明

重要风险提示

中国地区无法直接使用指定 API 平台。开始使用前，须确认网络环境、账号权限和平台入口均满足管理员下发的使用条件。

  • 连续使用超过 24 小时：可能触发账号安全校验、用量控制或服务限制。
  • 多个 CLI 进程并发使用，且并发超过 5：可能加速消耗额度，并触发动态速率限制或异常会话核验。
  • 未配置 Hosts：指定域名可能无法解析到要求的服务地址，导致登录、访问或请求失败。
  • 破限使用：包括规避平台配额、地区、账号或访问限制的行为，可能导致账号或服务权限受限。

模型测试题

不调用任何工具、也不调用联网，帮我做一下这个题目。

在一个黑色的袋子里放有三种口味的糖果，每种糖果有两种不同的形状（圆形和五角星形，不同的形状靠手感可以分辨）。现已知不同口味的糖和不同形状的数量统计如下表。参赛者需要在活动前决定摸出的糖果数目，那么，最少取出多少个糖果才能保证手中同时拥有不同形状的苹果味和桃子味的糖？（同时手中有圆形苹果味匹配五角星桃子味糖果，或者有圆形桃子味匹配五角星苹果味糖果都满足要求）

形状       苹果味  桃子味  西瓜味
圆形       7       9       8
五角星形   7       6       4

请给出严格证明，说明答案为什么可行，以及为什么更小的取出数量无法保证成功。

判定标准：正确答案应为 29 个。

使用前准备

  • 01 Claude Code CLI仅允许使用 Claude Code CLI；Claude App 存在账号风险。
  • 02 指定平台仅使用公司指定的 API 平台与账号配置。
  • 03 Hosts 配置完成本机 Hosts 配置并确认解析已生效。
  • 04 网络验证先确认指定网址可访问，再启动 CLI。

Claude Code CLI

  • Claude Code CLI：仅依照 Anthropic 官方安装文档或公司提供的官方安装指引安装、更新。
  • 仅允许使用 CLI；不使用 Claude App、来源不明的安装包、浏览器扩展、二次封装客户端或代登录工具。

指定 API 平台

账号和客户端须接入公司指定的 API 平台。该平台默认不向中国地区开放服务。请以平台页面、管理员通知和账号实际权限为准。

地区限制：出现“地区不可用”“无访问权限”或认证失败时，联系管理员核实账号、地区与平台权限。
项目应确认内容
平台入口API_PLATFORM_URL
登录方式指定账号、SSO 或 API Key 的获取与保管方式
客户端配置服务地址、模型权限和配置文件位置
支持渠道访问受限、认证失败或额度异常时的处理联系人

网络访问验证

使用者需自行准备满足平台访问条件的网络环境。完成网络连接后，先访问管理员下发的指定网址 API_PLATFORM_URL，确认页面或接口可正常响应，再启动 Claude Code CLI。
