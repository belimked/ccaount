普通用户用量统计接口说明

适用于 sub2api-plus（国内站 api.belimked.com、海外站 api.nicecode.de5.net）。本文只涉及普通用户查询自己的用量统计，可按模型（可选）和时间范围过滤。

概览

站点地址

站点BASE_URL说明
国内站https://api.belimked.com中国大陆访问。注册、充值、余额以此站为准
海外站https://api.nicecode.de5.net海外访问（中国大陆 IP 可能无法访问）
两个站点的用量统计相互独立。每个站点只统计在本站发生的请求：国内站的接口查不到海外站的用量，反之亦然。如需总用量，请分别查询两个站点后自行相加（下方 Python 脚本支持 --site all）。海外站的消费会异步同步到国内站并从余额中扣除，因此两站显示的余额可能存在短暂差异。

下文中的 BASE_URL 指上表中的任一站点地址，例如：

# 国内站
export BASE_URL=https://api.belimked.com
# 海外站
export BASE_URL=https://api.nicecode.de5.net

普通用户有两种认证方式：

方式凭证统计范围按模型过滤凭证是否会过期
API Keysk-xxx（固定）只统计当前这一个 Key不支持过滤参数；返回按模型的明细 model_stats不会（除非 Key 设置了过期时间或被禁用）
登录 JWTAccess Token + Refresh Token当前用户名下所有 Key，也可用 api_key_id 指定某个 Key支持 model= 参数会。Access Token 默认 24 小时，Refresh Token 默认 30 天

如何选择

  • 脚本 / 监控 / 第三方客户端：优先用 API Key 调 GET /v1/usage，不用处理登录、2FA 和验证码。
  • 需要按模型过滤，或要汇总名下多个 Key：用 JWT 调 GET /api/v1/usage/stats。
如果站点开启了登录验证码（Turnstile / 腾讯验证码），脚本很难直接调用 /auth/login。这时可以在浏览器登录后，从开发者工具中复制 refresh_token 给脚本使用，或者直接改用 API Key 方式。

方式一：API Key

GET/v1/usage

返回当前 API Key 的额度或余额、今日与累计用量、每日用量和按模型统计。

认证（三选一）

Header示例
AuthorizationBearer sk-xxxxxxxx
x-api-keysk-xxxxxxxx
x-goog-api-keysk-xxxxxxxx

Query 参数（全部可选）

参数说明默认值
start_datemodel_stats 的起始日期，格式 YYYY-MM-DD（按服务器时区）30 天前
end_datemodel_stats 的结束日期（包含当天）当前时间
daysdaily_usage 返回的天数，取值 1–9030
timezonedaily_usage 按天切分使用的时区，例如 Asia/Taipei服务器时区
start_date/end_date 格式错误时不会报错，会被忽略并使用默认值。days 超出范围会返回 400。

请求示例

curl -s "$BASE_URL/v1/usage?start_date=2026-01-01&end_date=2026-01-31&days=7&timezone=Asia/Taipei" \
  -H "Authorization: Bearer sk-xxxxxxxx"

响应说明

响应不包在 {code,data} 结构里，而是直接返回 JSON。根据 Key 的配置，分为三种形态：

mode触发条件特有字段
quota_limitedKey 设置了总额度或 5h/1d/7d 速率限制quota{limit,used,remaining,unit}、rate_limits[]、expires_at、days_until_expiry、status
unrestricted（订阅）Key 所属分组是订阅类型planName（分组名）、subscription{daily/weekly/monthly/five_hour 的 usage_usd 与 limit_usd, expires_at…}
unrestricted（余额）其他情况planName="钱包余额"、balance

三种形态都可能包含以下字段（统计查询失败时会省略，不影响整体响应）：

字段说明
usage.today / usage.total今日 / 累计的 requests、input_tokens、output_tokens、cache_creation_tokens、cache_read_tokens、total_tokens、cost（标准计费）、actual_cost（实际扣费）
usage.rpm / usage.tpm / usage.average_duration_ms当前 RPM、TPM、平均耗时
daily_usage[]按天统计：date、requests、input_tokens、output_tokens、cache_read_tokens、cache_write_tokens、total_tokens、cost、actual_cost
model_stats[]在 start_date–end_date 范围内按模型统计：model、requests、各类 tokens、cost、actual_cost。没有数据时省略

方式二：登录 JWT

/api/v1/* 下的接口都使用统一的响应包装：

{ "code": 0, "message": "success", "data": { ... } }

code != 0 或 HTTP 状态码非 2xx 时表示失败，错误原因见 message 和 reason。

POST/api/v1/auth/login

用邮箱和密码登录（限流：每分钟 20 次）。

Body 字段必填说明
email是邮箱
password是密码
turnstile_token / tencent_captcha_ticket / tencent_captcha_randstr站点开启验证码时必填人机验证凭证
curl -s -X POST "$BASE_URL/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"s4004567@blk.com","password":"your-password"}'

成功（未开启 2FA）：

{
  "code": 0, "message": "success",
  "data": {
    "access_token": "eyJhbGciOi...",
    "refresh_token": "rt_...",
    "expires_in": 86400,
    "token_type": "Bearer",
    "user": { "id": 12, "email": "s4004567@blk.com", ... }
  }
}

账号开启了 TOTP 两步验证时，返回的是临时凭证，需要继续调用 /login/2fa：

{ "code": 0, "message": "success",
  "data": { "requires_2fa": true, "temp_token": "...", "user_email_masked": "s***7@blk.com" } }
POST/api/v1/auth/login/2fa
Body 字段说明
temp_token上一步返回的临时凭证
totp_code6 位动态验证码
curl -s -X POST "$BASE_URL/api/v1/auth/login/2fa" \
  -H "Content-Type: application/json" \
  -d '{"temp_token":"...","totp_code":"123456"}'

成功后返回的 data 与普通登录相同。

POST/api/v1/auth/refresh

用 Refresh Token 换取新的 Access Token（限流：每分钟 30 次）。响应会带回新的 refresh_token，请用它替换本地保存的旧值。

curl -s -X POST "$BASE_URL/api/v1/auth/refresh" \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"rt_..."}'
{ "code": 0, "message": "success",
  "data": { "access_token": "eyJ...", "refresh_token": "rt_...", "expires_in": 86400, "token_type": "Bearer" } }
服务端配置默认值含义
jwt.expire_hour24Access Token 有效期（小时，最大 168）
jwt.access_token_expire_minutes0大于 0 时优先使用，单位为分钟
jwt.refresh_token_expire_days30Refresh Token 有效期（天）
GET/api/v1/usage/stats

主要查询接口。返回当前用户在指定条件下的汇总用量。统计范围固定为当前登录用户，无法查询其他用户。

Header：Authorization: Bearer <access_token>

Query 参数（全部可选）

参数说明
model模型名，精确匹配请求时传入的模型名（例如 claude-sonnet-4-5）。不传则统计所有模型
api_key_id只统计自己名下的某个 Key。传入他人的 Key ID 会被拒绝
group_id按分组过滤
start_date / end_dateYYYY-MM-DD，end_date 包含当天。格式错误返回 400
periodtoday | week（最近 7 天）| month（最近 1 个月）。未传 start_date 时生效
timezone解析日期使用的时区，例如 Asia/Taipei
streamtrue/false，按是否流式请求过滤
request_type / billing_type / billing_mode进阶过滤条件，一般不需要
时间参数都不传时，默认统计最近 7 天（含今天）。

请求示例

# 某模型、本月
curl -s "$BASE_URL/api/v1/usage/stats?model=claude-sonnet-4-5&start_date=2026-01-01&end_date=2026-01-31&timezone=Asia/Taipei" \
  -H "Authorization: Bearer $ACCESS_TOKEN"

# 所有模型、今天
curl -s "$BASE_URL/api/v1/usage/stats?period=today&timezone=Asia/Taipei" \
  -H "Authorization: Bearer $ACCESS_TOKEN"

GET/api/v1/usage

逐条返回使用记录（分页），过滤参数与 /usage/stats 相同，另外支持 page、page_size、sort_by（默认 created_at）和 sort_order（默认 desc）。适合对账或导出。

错误与注意事项

情况表现处理
Access Token 过期或无效HTTP 401调用 /auth/refresh 后重试
Refresh Token 过期或已被使用/auth/refresh 返回 401重新登录
API Key 无效HTTP 401，API_KEY_REQUIRED / authentication_error检查 Key
日期格式错误（JWT 接口）HTTP 400使用 YYYY-MM-DD 格式
api_key_id 不属于自己HTTP 4xx只能传自己名下的 Key ID
请求过于频繁HTTP 429/api/v1/usage/* 属于重型查询，有面板限流，请降低频率
  • model 过滤匹配的是客户端请求时传入的模型名，不是上游实际映射后的模型名。
  • 金额单位均为 USD。
  • 统计数据可能有短暂缓存，不适合用作实时计费依据。

Python 脚本

依赖：pip install requests，需要 Python 3.8 及以上版本。

API Key 版（推荐用于脚本）

#!/usr/bin/env python3
"""用 API Key 查询自己的用量：python usage_by_key.py [--site cn|overseas|all] [--model 模型名] [--start 2026-01-01] [--end 2026-01-31]"""
import argparse
import os
import sys

import requests

SITES = {
    "cn": ("国内站", "https://api.belimked.com"),
    "overseas": ("海外站", "https://api.nicecode.de5.net"),
}
API_KEY = os.environ.get("SUB2API_API_KEY", "")


def fetch_usage(base_url, start=None, end=None, days=30, tz=None):
    params = {"days": days}
    if start:
        params["start_date"] = start
    if end:
        params["end_date"] = end
    if tz:
        params["timezone"] = tz
    resp = requests.get(
        f"{base_url}/v1/usage",
        headers={"Authorization": f"Bearer {API_KEY}"},
        params=params,
        timeout=30,
    )
    resp.raise_for_status()
    return resp.json()


def report(name, data, model):
    print(f"===== {name} =====")
    print(f"模式: {data.get('mode')}  套餐: {data.get('planName', '-')}  "
          f"剩余: {data.get('remaining', '-')} {data.get('unit', '')}")

    usage = data.get("usage") or {}
    for label in ("today", "total"):
        u = usage.get(label)
        if u:
            print(f"[{label}] 请求 {u['requests']}  tokens {u['total_tokens']}  "
                  f"标准 ${u['cost']:.4f}  实扣 ${u['actual_cost']:.4f}")

    models = data.get("model_stats") or []
    if model:
        models = [m for m in models if m["model"] == model]
    print("\n按模型统计:")
    if not models:
        print("  (无数据)")
    for m in models:
        print(f"  {m['model']:<32} 请求 {m['requests']:>7}  tokens {m['total_tokens']:>12}  "
              f"实扣 ${m['actual_cost']:.4f}")

    print("\n每日用量:")
    for d in data.get("daily_usage") or []:
        print(f"  {d['date']}  请求 {d['requests']:>6}  tokens {d['total_tokens']:>11}  实扣 ${d['actual_cost']:.4f}")
    print()


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--site", choices=["cn", "overseas", "all"], default="cn", help="国内站 / 海外站 / 两者")
    p.add_argument("--model", help="只显示该模型（在 model_stats 中本地过滤）")
    p.add_argument("--start", help="YYYY-MM-DD")
    p.add_argument("--end", help="YYYY-MM-DD")
    p.add_argument("--days", type=int, default=7, help="daily_usage 天数 1-90")
    p.add_argument("--tz", default="Asia/Taipei")
    args = p.parse_args()

    if not API_KEY:
        sys.exit("请设置环境变量 SUB2API_API_KEY")

    sites = ["cn", "overseas"] if args.site == "all" else [args.site]
    for key in sites:
        name, base_url = SITES[key]
        try:
            data = fetch_usage(base_url, args.start, args.end, args.days, args.tz)
        except requests.RequestException as e:
            print(f"===== {name} =====\n请求失败: {e}\n")
            continue
        report(name, data, args.model)


if __name__ == "__main__":
    main()

JWT 版（支持按模型过滤，自动刷新 Token）

通过 --site 选择国内站、海外站或同时查询两者。两个站点的登录态相互独立，各自登录、各自保存 token。首次运行时用邮箱和密码登录（如开启了 2FA，会提示输入验证码），之后把 token 保存到本地文件，并自动续期。如果站点开启了验证码，可以先从浏览器复制 refresh_token，通过 SUB2API_REFRESH_TOKEN_CN 或 SUB2API_REFRESH_TOKEN_OVERSEAS 环境变量提供给脚本。

#!/usr/bin/env python3
"""用登录态查询自己的用量：python usage_by_jwt.py [--site cn|overseas|all] [--model 模型名] [--start ...] [--end ...] [--period today|week|month] [--by-model]"""
import argparse
import getpass
import json
import os
import stat
import time
from pathlib import Path

import requests

SITES = {
    "cn": ("国内站", "https://api.belimked.com"),
    "overseas": ("海外站", "https://api.nicecode.de5.net"),
}


class ApiError(Exception):
    pass


def _unwrap(resp):
    try:
        body = resp.json()
    except ValueError:
        raise ApiError(f"HTTP {resp.status_code}: {resp.text[:200]}")
    if resp.status_code >= 400 or body.get("code", 0) != 0:
        raise ApiError(f"HTTP {resp.status_code}: {body.get('message')} {body.get('reason', '')}".strip())
    return body.get("data")


class Client:
    def __init__(self, site):
        self.name, self.base_url = SITES[site]
        self.env_suffix = site.upper()
        self.token_file = Path.home() / f".sub2api_token_{site}.json"
        self.session = requests.Session()
        self.tokens = self._load()

    def _load(self):
        if self.token_file.exists():
            return json.loads(self.token_file.read_text())
        rt = os.environ.get(f"SUB2API_REFRESH_TOKEN_{self.env_suffix}")
        return {"refresh_token": rt} if rt else {}

    def _save(self, data):
        self.tokens = {
            "access_token": data["access_token"],
            "refresh_token": data.get("refresh_token") or self.tokens.get("refresh_token"),
            "expires_at": time.time() + int(data.get("expires_in") or 3600) - 60,
        }
        self.token_file.write_text(json.dumps(self.tokens))
        os.chmod(self.token_file, stat.S_IRUSR | stat.S_IWUSR)

    def login(self):
        print(f"登录{self.name} {self.base_url}")
        email = os.environ.get("SUB2API_EMAIL") or input("Email: ")
        password = os.environ.get("SUB2API_PASSWORD") or getpass.getpass("Password: ")
        data = _unwrap(self.session.post(f"{self.base_url}/api/v1/auth/login",
                                         json={"email": email, "password": password}, timeout=30))
        if data.get("requires_2fa"):
            code = input(f"2FA 验证码 ({data.get('user_email_masked', '')}): ").strip()
            data = _unwrap(self.session.post(f"{self.base_url}/api/v1/auth/login/2fa",
                                             json={"temp_token": data["temp_token"], "totp_code": code},
                                             timeout=30))
        self._save(data)

    def refresh(self):
        rt = self.tokens.get("refresh_token")
        if not rt:
            return False
        try:
            data = _unwrap(self.session.post(f"{self.base_url}/api/v1/auth/refresh",
                                             json={"refresh_token": rt}, timeout=30))
        except ApiError:
            return False
        self._save(data)
        return True

    def ensure_token(self):
        if self.tokens.get("access_token") and self.tokens.get("expires_at", 0) > time.time():
            return
        if not self.refresh():
            self.login()

    def get(self, path, params=None):
        self.ensure_token()
        for attempt in range(2):
            resp = self.session.get(f"{self.base_url}{path}", params=params, timeout=60,
                                    headers={"Authorization": f"Bearer {self.tokens['access_token']}"})
            if resp.status_code == 401 and attempt == 0:
                if not self.refresh():
                    self.login()
                continue
            return _unwrap(resp)


def build_params(args):
    params = {"timezone": args.tz}
    if args.model:
        params["model"] = args.model
    if args.api_key_id:
        params["api_key_id"] = args.api_key_id
    if args.start:
        params["start_date"] = args.start
    if args.end:
        params["end_date"] = args.end
    if not args.start and args.period:
        params["period"] = args.period
    return params


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--site", choices=["cn", "overseas", "all"], default="cn", help="国内站 / 海外站 / 两者")
    p.add_argument("--model", help="模型名（可选）")
    p.add_argument("--api-key-id", type=int, help="只统计自己名下的某个 Key（可选）")
    p.add_argument("--start", help="YYYY-MM-DD")
    p.add_argument("--end", help="YYYY-MM-DD")
    p.add_argument("--period", choices=["today", "week", "month"])
    p.add_argument("--tz", default="Asia/Taipei")
    p.add_argument("--by-model", action="store_true", help="额外输出按模型明细")
    args = p.parse_args()

    params = build_params(args)
    print(f"过滤条件: {params}\n")
    sites = ["cn", "overseas"] if args.site == "all" else [args.site]
    total_cost = 0.0
    for site in sites:
        client = Client(site)
        print(f"===== {client.name} ({client.base_url}) =====")
        try:
            total_cost += show(client, params, args.by_model)
        except (ApiError, requests.RequestException) as e:
            print(f"请求失败: {e}")
        print()
    if len(sites) > 1:
        print(f"两站实际扣费合计: ${total_cost:.4f}")


def show(client, params, by_model):
    s = client.get("/api/v1/usage/stats", params)
    print(f"请求数        {s['total_requests']}")
    print(f"输入 tokens   {s['total_input_tokens']}")
    print(f"输出 tokens   {s['total_output_tokens']}")
    print(f"缓存写/读     {s['total_cache_creation_tokens']} / {s['total_cache_read_tokens']}")
    print(f"总 tokens     {s['total_tokens']}")
    print(f"标准计费      ${s['total_cost']:.4f}")
    print(f"实际扣费      ${s['total_actual_cost']:.4f}")
    print(f"平均耗时      {s['average_duration_ms']:.0f} ms")

    if by_model:
        m = client.get("/api/v1/usage/dashboard/models", params)
        print(f"\n按模型 ({m['start_date']} ~ {m['end_date']}):")
        for row in m["models"]:
            print(f"  {row['model']:<32} 请求 {row['requests']:>7}  tokens {row['total_tokens']:>12}  "
                  f"实扣 ${row['actual_cost']:.4f}")
    return s["total_actual_cost"]
