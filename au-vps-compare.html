澳洲 VPS 对比：2GB / 4GB 内存

用于部署 AxleoCollect 后台（Go 单二进制 + SQLite + 本地照片存储，几十个中介使用）。

数据采集：2026-11-19 ~ 11-20。来源为各家官方 API / 官网价格页，价格随时可能变动，下单前以结算页为准。

结论

首选：AWS Lightsail 悉尼 2GB

约 US$12/月，2 vCPU、60GB SSD，自带每日快照，可配合 S3 悉尼做异机备份。已有 AWS 澳洲账号，开机最快。

备选：BinaryLane 2GB

A$9.80/月，澳洲本土商家，NVMe 40GB、流量 2TB。同配置大约是 Lightsail 的一半价钱，但只有 1 vCPU。

便宜但有代价：OVH VPS-1 / HostHatch

OVH 4GB 只要 A$6.29 起（不含 GST），但悉尼每月流量 500GB 封顶，超出后限速。HostHatch 磁盘小、CPU 共享。

说明

  1. 币种：USD 为美元，AUD 为澳元。美元报价的商家对澳洲账户通常另加 10% GST；OVH 标的是不含 GST 的价格。BinaryLane 是澳洲本土商家，以结算页为准。
  2. 价格来源：Lightsail 来自 AWS Price List API（悉尼 ap-southeast-2，按小时价 × 744 小时折算）；Vultr、Linode 来自官方公开 API；BinaryLane、DigitalOcean、OVH 来自官网价格页；HostHatch 来自官网前端套餐数据。
  3. 订购要求：所有商家都可以用个人身份注册，企业可以填公司名和 ABN 开发票。付款方式和是否要求证件验证是根据各家的常见做法整理的，没有逐家实际注册核实，以注册页为准。新账号被风控要求上传证件或预充值的情况各家都有。
  4. Contabo：最小的 Cloud VPS 4 就是 4 vCPU / 8GB / 100GB SSD，基础价 US$6.6 起，悉尼机房另收地区费（页面动态加载，没有抓到具体金额），所以没有放进 2GB / 4GB 表里。入口：contabo.com/en/locations/australia。
  5. GreenCloudVPS 没有澳洲机房（亚太只有新加坡、香港、东京、河内），不列入。
  6. 链接未验证：Vultr 的官网在采集时网络连不上，链接是官方常用地址，请在浏览器里确认。其余链接均已用 curl 检查返回 200。
  7. 项目需求：2GB 内存就能跑；磁盘建议 ≥ 40GB（照片 + 14 份每日备份）；数据放在澳洲境内对隐私法 / DNCR 合规更有利。
