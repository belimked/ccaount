NiceCode API 访问指引

访问说明 · 代理规则配置 · 连通性验证

重要提示：本站点默认拦截中国大陆地区 IP。 大陆用户直接访问将被拒绝，请先自行开启科学上网（代理），并确保访问该域名的流量走代理节点，而不是直连（DIRECT）。

API 地址

https://api.nicecode.de5.net

在客户端 / SDK 中将 Base URL 设置为以上地址。

1关闭系统代理，开启虚拟网卡模式（TUN）

在 设置 → 系统设置 中：关闭「系统代理」，开启「虚拟网卡模式（TUN）」。

TUN 模式会接管包括命令行工具（Claude Code / Codex）在内的全部流量；而系统代理通常只对浏览器等部分程序生效，终端工具不会走代理。

2在代理客户端中添加规则（图形界面）

  1. 点击 「保存」，确认规则列表中出现该规则且开关为开启状态。

提示：如果你的客户端没有「节点选择」，请选择实际可用的代理策略组（如「Proxy」「🚀 节点选择」或某个海外节点）。建议优先选择日本 / 新加坡 / 美国等海外节点。

3配置文件方式（可选）

如果你直接编辑 Clash / mihomo 的 YAML 配置，在 rules: 中添加下面一行，并放在 GEOIP,CN 和 MATCH 规则之前：

rules:
  - DOMAIN-SUFFIX,api.nicecode.de5.net,节点选择
  # ... 其它规则
  - GEOIP,CN,DIRECT
  - MATCH,节点选择

规则自上而下匹配，命中即停止，所以自定义规则越靠前优先级越高。

4确认代理已生效

按第 1 步开启 TUN 后，浏览器与命令行工具均无需额外配置。如果无法使用 TUN，可退而在终端中手动设置代理环境变量：

# macOS / Linux（端口以客户端显示为准，常见 7890 / 7897）
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890

# Windows PowerShell
$env:HTTPS_PROXY="http://127.0.0.1:7890"
$env:HTTP_PROXY="http://127.0.0.1:7890"

测试连通性：

curl -I https://api.nicecode.de5.net

能正常返回 HTTP 响应头即为 连接成功。也可在客户端「连接」页面查看该域名是否走了代理节点。

5常见问题

  • 返回 403 / 拒绝访问：流量仍是大陆 IP 出口。检查规则是否启用、出站目标是否为 DIRECT、节点是否可用。
  • 浏览器能访问、终端不行：终端未走代理。确认已关闭系统代理并开启 TUN 模式（见第 1 步），或设置上面的代理环境变量。
  • 添加规则后无变化：点击「刷新规则」，或重启客户端；同时检查是否有更靠前的规则把该域名指向了 DIRECT。
  • 连接超时：切换其它节点重试。
