在大陆开一家国产模型 Token 中转站，需要准备什么

以公司主体面向用户售卖国产大模型 API Token，用 sub2api 做网关，收款走支付宝/微信官方商户。本页按办理顺序整理：域名、服务器、资质、支付、模型采购，每条结论都附出处。

适用范围：中国大陆 · 国产已备案模型不含：GPT / Claude 等境外模型

00办理顺序与周期

ICP 备案是前置条件：支付签约、许可证申请都要求网站已备案。可以先完成第 1–4 步，再把第 5、6、7 步并行推进。

  1. 0注册公司，开对公账户经营范围含"信息技术服务、增值电信业务"等 · 市场监管局、银行1–3 周
  2. 1域名实名到公司名下必要时转入国内注册商3–5 天
  3. 2购买国内云服务器阿里云 / 腾讯云 / 华为云等当天
  4. 3ICP 备案云厂商初审 → 省通信管理局1–3 周
  5. 4公安联网备案网站开通后 30 日内1–2 周
  6. 5经营性 ICP 许可证（B25）省通信管理局45–60 工作日
  7. 6算法备案 + 生成式 AI 登记网信办 · 登记由属地网信办办理1–3 个月
  8. 7支付宝 / 微信支付商户签约1–2 周
  9. 8上线公示所用模型名称和备案号，添加 AI 内容标识—

01域名：已有的域名能不能用？

要满足四个条件才能用。其中后缀是硬条件：.ai 目前不在工信部批复的可备案后缀里，不能备案。其他三项都可以补办。
检查项要求不满足怎么办
① 后缀顶级域名必须在工信部批复的可备案后缀列表中。.com .cn .net .top .xyz 等常见后缀可以备案，.ai 目前不能换一个可备案后缀的域名，比如注册同名的 .com 或 .cn
② 注册商必须是工信部批准的境内域名注册服务机构GoDaddy、Namecheap、Cloudflare 等境外注册商的域名，要转入阿里云、腾讯云等国内注册商
③ 实名持有者完成实名认证，且与备案主体一致（公司备案就要实名到公司名下）在注册商处办理持有者变更，改为公司主体，同步需要 2–3 天
④ 有效期距离到期通常要有 45 天以上先续费

自检方法：用阿里云或腾讯云备案页面上的"域名检测"工具，输入域名，可以一次查清后缀和注册商是否符合要求。

如果现有域名是 .ai：可以保留，用作海外品牌站或跳转入口，但国内服务器上提供服务的主域名必须是可备案的后缀。

出处：阿里云 · ICP 备案域名核验要求 · 腾讯云 · 准备备案域名 · 工信部备案管理系统

02国内服务器：要不要备案？什么配置？

要备案。服务器在中国大陆，并且通过域名对外提供 Web/API 服务，就必须先做 ICP 备案，否则 80/443 端口会被云厂商拦截。但 ICP 备案只解决"网站能开"的问题，收费经营还需要第 03 节里的许可证和 AI 相关手续。
  • ICP 备案在服务器所在的云厂商处提交。一般要求在该厂商有符合条件的实例，比如阿里云通常要求 ECS 为包年包月且不少于 3 个月，以厂商规则为准。
  • 备案通过后 30 日内，要在 全国互联网安全管理服务平台 办理公安联网备案。

关于 sub2api（务必先读）

sub2api 是一个 Go 语言写的开源 AI API 网关（LGPL-3.0）。它的核心定位是把 Claude、OpenAI、Gemini、Grok 的订阅账号统一接入，支持"拼车共享"。它也支持 API Key 类型的上游，README 提到可以接入自定义 base_url 的 OpenAI 兼容上游，部署后需要在后台实际验证。内置支付支持 EasyPay、支付宝、微信支付和 Stripe。依赖 PostgreSQL 15+ 和 Redis 7+。

项目免责声明原文要点

使用本项目可能违反 Anthropic 等上游的服务条款，账号被封等风险由使用者自行承担。

✓ 国内售卖场景可以这样用

  • 上游只接国产模型的按量付费 API Key，并且是企业账号
  • 支付走支付宝/微信官方直连商户
  • 用自有品牌名做模型别名，页面公示真实上游模型和备案号

✗ 不要这样用

  • 接 Claude/ChatGPT 等订阅账号做拼车
  • 用 EasyPay/易支付等"四方"聚合收款，可能涉嫌帮信、非法经营
  • 把 Coding Plan 等订阅套餐拼车转售

备选网关：new-api，以及它的上游项目 one-api。这两个项目原生面向"多家 API Key + 计费"的场景，和按量售卖 Token 的模式更契合。

经营性 ICP 许可证（B25）详解

依据《电信业务经营许可管理办法》（工信部令第 42 号，2017-09-01 施行）、《电信条例》、《互联网信息服务管理办法》。业务种类为《电信业务分类目录》中的 B25 信息服务业务（互联网信息服务）。有效期 5 年（第十四条）。

证件编号形如「京 ICP 证 030173 号」，和 ICP 备案号（「京 ICP 备 xxxxx 号-1」）是两回事，网站底部要同时标注。

省内证还是跨地区证？注册资本差 10 倍

这是最容易踩的坑，《管理办法》第六条写得很明确：

类型审批机关注册资本下限周期
省内（地网）省通信管理局100 万元约 45–60 工作日
跨地区（全网）工业和信息化部1000 万元更长

判定口径各地不完全一致，一般看经营场所、服务器和分支机构是否跨省。网站面向全国用户访问，通常仍按省内证办，但必须先问清属地管局的口径：如果被要求办全网证，1000 万注册资本这道门槛会直接改变公司架构规划。办了省内证之后要跨省经营，得先升级成全网证，再到当地管局做跨省备案，遵循"先备案、后经营"。

外资提示

有外资股东的，按《外商投资电信企业管理规定》单独走审批。增值电信业务外方持股一般上限 50%，北京、上海、海南、深圳等试点区域对部分业务有放开。

申请条件

  1. 依法设立的公司（内资；有外资按上条处理）。
  2. 注册资本达标，认缴即可，但部分省份会看实缴或财务报表。
  3. 有与开展业务相适应的资金和专业人员。
  4. 有为用户提供长期服务的信誉或能力。
  5. 公司及主要出资者、主要经营管理人员三年内无违反电信监督管理制度的违法记录。
  6. 人员与社保（各省细则，通常要求）：至少 3 名全职人员，分别担任许可负责人、网络信息安全负责人、客服负责人；网安负责人一般要求计算机相关专业大专及以上学历；需企业直缴的近 1 个月社保记录（第三方代缴无效），海南等省要求 3 个月。

对本项目，安全保障措施要写明：内容安全审核怎么做、用户实名怎么做、对话日志留存多久、发现违法内容的处置流程。这部分和算法备案的安全自评估报告内容大量重合，两份材料一起写能省不少时间。

办理流程

  1. 前置：公司注册好（经营范围含"第二类增值电信业务"）→ 域名实名到公司 → 网站上线 → ICP 备案完成。管局审核时会打开网站看，页面内容、价格、用户协议、联系方式都要齐全。
  2. 线上申报：登录 电信业务市场综合管理信息系统 注册企业账号，填报并上传材料。2025 年 10 月起全面推行电子证照，与纸质证照效力相同，可全流程线上办。
  3. 受理与补正：管局形式审查，材料不全会一次性告知补正。安全保障措施和业务方案被退回修改是常事。
  4. 审查：自收到全部申请材料之日起 60 日内审查完毕（第十条）。加上补正来回，实际 45–60 个工作日比较常见。
  5. 发证：核发经营许可证（电子证照），在网站显著位置标注证号。

无证经营的处罚

《管理办法》第四十六条：擅自经营电信业务或超范围经营的，按《电信条例》第六十九条处罚——责令改正，没收违法所得，处违法所得 3 倍以上 5 倍以下罚款；没有违法所得或违法所得不足 1 万元的，处 1 万元以上 10 万元以下罚款；情节严重的责令停业整顿，并可列入失信名单。

费用：管局不收费。代办市场价通常 1–3 万元，主要是替你写业务方案和安全保障措施、跟进补正。

"备案"和"登记"的区别（网信办公告原文）

  • 备案由国家网信办负责，针对提供生成式 AI 服务的模型本身。
  • 登记由地方网信办开展，针对"通过 API 接口或其他方式直接调用已备案模型能力的生成式人工智能应用或功能"。
  • 截至 2026-06-30，累计 988 款服务完成备案，598 款应用或功能完成登记。
  • 公示义务：已上线的应用"应在显著位置或产品详情页面公示所使用已备案或登记生成式人工智能服务情况，注明模型名称、备案号或上线编号"。

需要提前和属地网信办确认的两个问题

  1. 纯 API 分发（B2B 卖 Token 给开发者）算不算"面向公众提供服务"：目前没有统一口径。如果同时提供网页聊天界面（C 端），一般会被认定为需要登记。
  2. "二次处理"是否构成实质性修改：有律师文章指出，如果对模型输出做了过滤、重组等二次处理，可能会被要求改走更重的大模型备案。自有品牌别名、system prompt 注入属于轻度处理，登记材料里要如实说明。

上游厂商（阿里云、火山引擎等）通常会为调用其模型的客户提供登记所需的模型备案号和授权材料，签约时可以一并索要。

04支付商户

支付宝商户号（重点）

推荐产品：PC 端用"电脑网站支付"，H5 页面用"手机网站支付"。备选"当面付"（生成付款二维码），门槛相对低，但对网站类虚拟商品的适配要看审核结果。

签约条件（电脑网站支付，官方文档）：

  • 支持企业、个体工商户、个人账号。建议直接用企业账号，和公司、ICP 备案主体保持一致。
  • 网站能正常访问，经营内容明确，商品信息完整：要有价格页或充值套餐页、用户协议、隐私政策、联系方式。

流程：

  1. 注册支付宝企业账号，完成企业实名认证（营业执照、法人信息、对公账户打款验证）。
  2. 登录 支付宝开放平台，创建网页/移动应用，拿到 AppID。
  3. 在商家平台签约"电脑网站支付"和"手机网站支付"，提交网站和经营信息，等待审核（一般几个工作日）。
  4. 在开放平台为应用配置接口加签方式（推荐公钥证书模式），并绑定已签约的产品。
  5. 先用沙箱环境联调，确认异步通知（notify_url）和回调验签都没问题，再切到正式环境。
  6. 在 sub2api 后台填入 AppID、应用私钥、支付宝公钥证书等参数。

费率：标准费率一般约 0.6%，以签约页面显示为准。

风控提示："虚拟商品/充值"是高风控类目。商品页要写清楚"服务内容 = 模型 API 调用额度"，退款规则要明确。不要用个人收款码，不要接入易支付等四方平台。

出处：电脑网站支付申请条件 · 如何签约电脑网站支付 · ICP 备案授权函 · 商家账号入驻签约指引

微信支付：已有商户号能否沿用？

满足以下四个条件就可以沿用，不必新开。最常见的卡点是经营类目：原来如果是餐饮、零售等无关类目，要先申请变更。
条件说明
① 主体一致商户号主体 = 运营网站的公司 = ICP 备案主体。不一致时要提供网站授权函；AppID 主体不一致时要签《微信支付联合运营承诺函》并经过审核
② 类目匹配要能覆盖"软件/IT 服务、在线充值"这类业务。不匹配就在商户平台申请类目变更，变更不通过只能新开
③ 开通 Native 支付PC 网站扫码支付用 Native 支付：商户平台"产品中心 → Native 支付 → 申请开通"，审核一般在 7 个工作日内
④ 绑定 AppID必须是已认证的服务号，或政府、媒体类型的公众号。订阅号不行

申请 Native 支付要准备：经营场景选"PC 网站"；已 ICP 备案的网站域名；网站授权函（网站备案主体和商户主体不一致时需要，按模板打印并加盖公章）；已认证服务号的 AppID；规范的商户简称（不能只用人名或无意义文字）和真实可打通的客服电话。

注意：商户号和 AppID 关联后暂不支持解绑，关联前要确认好。

出处：申请 Native 支付权限指引 · 管理商户号绑定的 APPID · APPID 授权管理

05国内模型：买哪些？去哪买？

先搞清楚：Coding Plan 不能拿来转售

各家的 Coding Plan / Token Plan（包月订阅）都不能用于中转售卖。以阿里云百炼的条款为例：仅限订阅账号本人使用，严禁出借、共享、出售 API Key；只能在编程工具中用于编程用途，禁止用于自定义应用后端和自动化批量调用；违规会被暂停订阅或封禁 Key。其他家也有类似限制。

转售场景只能用"按量付费 API"，并使用企业实名账号。量大以后，可以谈企业合同或渠道/分销协议，拿到折扣和明确的转售授权。条款原文

采购策略：

  1. 主通道选一个大厂聚合平台（百炼或方舟）：一份合同、一张发票覆盖多家模型，备案材料也好要。
  2. 直连通道用 DeepSeek 官方，价格最低。
  3. 备用通道用硅基流动或另一个大厂平台，在网关里配置失败自动切换。
  4. 签约前逐条阅读各平台《服务协议》里关于转售、再分发、二次封装的条款。条款不明确时，走企业商务渠道拿书面授权。
  5. 记录每个上游模型的备案号，用于页面公示。

风险汇总

风险后果规避
无证经营没有经营性 ICP 许可证就收费，可能被责令整改、罚款、关停先办许可证，取得前只做免费内测
未登记提供生成式 AI 服务违反《生成式人工智能服务管理暂行办法》办理算法备案和登记，页面公示备案号
接入境外模型或订阅拼车境外模型没有在国内备案，还违反上游条款只接国产已备案模型的按量 API
转售订阅套餐违反 Coding Plan 条款，会被封号只用按量 API 和企业合同
四方或个人码收款资金被冻结，可能涉嫌帮信只用支付宝/微信官方直连
模型"掺水"或冒充消费欺诈，口碑崩盘别名和实际上游一致，定价如实
日志缺失无法满足留存和配合监管的要求日志留存 ≥ 6 个月，接入内容安全审核
