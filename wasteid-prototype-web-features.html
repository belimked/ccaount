2. 功能清单

编号一级菜单二级菜单 功能说明优先级
W01登录—账号密码登录演示账号，不做真实认证必做
W02首页—概览在用设备数、逾期设备数、近 7 天抽取 / 转运 / 卸货次数、待审核司机数必做
W03地点管理—地点列表搜索；按区域、状态筛选必做
W04新增 / 编辑 / 停用地点名称、地址、坐标（地图选点）、协议编号必做
W05地点详情基本信息、地点下的设备列表必做
W06设备管理设备列表列表、搜索、筛选按状态（在用 / 停用 / 已拆除）、设备类型、逾期、负责运输公司筛选必做
W07新增 / 编辑 / 停用设备所属地点、Device Ref、设备类型、废物类型、容积、服务周期（周）、审批类别、风险等级、位置描述、负责运输公司、二维码；修改自动写入变更记录必做
W08设备详情页签：基本信息、服务日期、抽取记录、变更记录必做
W09服务日期计算下次服务日期 = 上次服务日期 + 服务周期×7 天；逾期标红并显示逾期周数必做
W10CSV 导入上传 CSV支持现有 WasteID 设备导出格式必做
W11导入预览与执行按 Device Ref 匹配：新增 N 条、更新 N 条、出错 N 条（列出原因）；确认后执行，更新内容写入变更记录（来源 = CSV 导入）必做
W12导入历史每次导入的时间、操作人、文件名、各类条数必做
W13变更记录变更查询全部设备的修改记录：设备、字段、原值、新值、修改人、时间、来源（Web / App / CSV）；可筛选，点进跳到设备必做
W14运输公司公司列表列表、新增、编辑、停用公司名称、ABN、联系人、电话、地址、状态必做
W15公司详情页签：基本信息、司机、车辆、负责的设备、作业记录必做
W16司机司机列表、新增、审核、停用所属公司、姓名、电话、账号、状态（待审核 / 正常 / 停用）；可按公司筛选必做
W17车辆车辆列表、新增、编辑、停用所属公司、车牌、车型（小车 / 大车）、罐体容积、车辆二维码、当前车上存量；可按公司筛选必做
W18车辆详情基本信息、当前存量、作业记录（抽取、转入 / 转出、卸货）必做
W19作业记录抽取记录列表与详情设备、地点、公司、司机、车辆、抽取量、时间、位置、位置距离、照片、异常标记（位置 / 容量）必做
W20转运记录列表与详情公司、司机、转出车、转入车、转运量、时间、位置必做
W21卸货记录列表与详情公司、司机、车辆、处理厂、卸货量、时间、位置必做
W22流向追溯废油流向追溯从抽取查到经过哪些车、卸到哪个处理厂；从卸货反查来源设备必做
W23处理厂管理—列表、新增、编辑、停用名称、地址、坐标、处理厂二维码必做
W24处理厂详情基本信息、卸货记录必做
W25通用—二维码展示 / 打印设备、车辆、处理厂详情页均可显示并打印二维码必做

原型不含：后端与数据库、离线模式、警告与罚款、报表导出、历史数据迁移、多租户。
