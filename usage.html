Claude 账号使用说明

适用于 Claude 个人账号与 Team 成员的登录、客户端、指定 API 平台、Hosts 配置和日常账号安全管理。

使用前准备

  • 01 官方客户端仅安装官方 Claude App 或 Claude Code CLI。
  • 02 指定平台仅使用公司指定的 API 平台与账号配置。
  • 03 网络验证先确认指定网址可访问，再启动客户端。
  • 04 Hosts 配置完成本机 Hosts 配置并确认解析已生效。

官方客户端与 CLI

  • Claude Desktop / 移动端 App：仅从官方 Claude 下载页 或官方应用商店安装。
  • Claude Code CLI：仅依照 Anthropic 官方安装文档或公司提供的官方安装指引安装、更新。
  • 不使用来源不明的安装包、浏览器扩展、二次封装客户端或代登录工具。

指定 API 平台

账号和客户端须接入公司指定的 API 平台。该平台默认不向中国地区开放服务；请以平台页面、管理员通知和账号实际权限为准。

地区限制：出现“地区不可用”“无访问权限”或认证失败时，联系管理员核实账号、地区与平台权限。

网络访问验证

使用者需自行准备满足平台访问条件的网络环境。完成网络连接后，先访问管理员下发的指定网址 API_PLATFORM_URL，确认页面或接口可正常响应，再启动 Claude App 或 Claude Code CLI。

Hosts 配置与生效验证

管理员会提供目标域名和对应 IP。以下示例中的 TARGET_IP、TARGET_DOMAIN 和 VERIFY_PATH 必须替换为实际下发值。

TARGET_IP TARGET_DOMAIN
系统Hosts 文件位置刷新 DNS 缓存
macOS/etc/hostssudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder
WindowsC:\Windows\System32\drivers\etc\hostsipconfig /flushdns
Linux/etc/hostssudo resolvectl flush-caches

验证命令

curl -vI https://TARGET_DOMAIN
  1. 连接日志应显示连接到 TARGET_IP，并能收到目标站点的 HTTP 响应。
  2. 在浏览器访问 https://TARGET_DOMAIN/VERIFY_PATH，结果应与管理员提供的预期页面或响应一致。
  3. 若仍解析到旧 IP，检查 Hosts 文件是否有重复或冲突条目，刷新 DNS 缓存后重启浏览器或客户端。

账号安全与使用

  • 使用真实、长期可访问的邮箱完成注册或登录，并按页面要求完成手机号验证。
  • 定期检查 Settings → Account → Active sessions；发现未知会话时立即退出并重新认证。
  • 不共享账号密码、Cookie、登录链接、验证码、API Key 或终端认证文件。
  • 付费套餐的实际额度以 Settings → Usage 显示的用量和重置时间为准。
